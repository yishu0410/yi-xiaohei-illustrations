# 易姐 IP

## 角色定义

易姐是本 skill 的第二个视觉 IP，与小黑并列，风格 DNA 完全共用（见 `style-dna.md`）。

易姐不是客服，不是礼仪小姐，不是电商主播，而是"出镜讲解的专业合伙人"：温和、自信、有温度，正在认真把一件事讲清楚或示范到位。

参考基准图：`assets/ip-reference/yijie-reference.jpg`（生成时如需校准形象，读这张图）。

## 外形

- 年轻职业女性，黑色齐肩短发（bob 头，微微内扣）。
- 白色西装外套 + 白衬衫，粗黑轮廓线勾勒，西装永远是白色，不换装。
- 面部极简淡彩：浅肤色、细眉、棕色眼睛、红唇。
- 表情：自信的浅笑，眼神有神但不夸张。与小黑的"空表情"相对——她是有温度的专业感。
- 线条风格：粗黑轮廓线 + 局部淡彩，仍守白底、手绘感、大量留白。

## 性格

- 专业、温和、有掌控感。
- 讲解时像在陪跑，不像在推销。
- 冷静但不冷漠，偶尔幽默。
- 与小黑是搭档关系：易姐主讲，小黑当她的荒诞系统操作员。

## 常见职责

让易姐承担核心动作：

- 比心（招牌动作，适合感谢/认可/交付节点）。
- 指方向、递东西、递话术卡片。
- 敲白板、捧资料、翻页讲解。
- 摊手提问、举手示意、竖大拇指。
- 握手（成交/合作节点）、抱臂思考。
- 牵着流程线走，带读者过一遍链路。

## 与小黑的分工与同框

| | 小黑 | 易姐 |
|---|---|---|
| 气质 | 荒诞、呆、冷幽默 | 专业、温和、有温度 |
| 擅长 | 系统隐喻、抽象操作、流程荒诞感 | 讲解、示范、人际节点、个人品牌 |
| 适用文章 | AI 工作流、方法论、系统结构 | 职场成长、培训招生、增长方法、客户沟通 |

- 一张图可以两人同框：易姐主讲/示范，小黑做荒诞辅助（搬箱子、拉错线、卡在机器里）。同框时小黑仍不许卖萌，易姐不许变成主角特写大头照。
- 两人同框时，画面主体仍只讲一个核心结构。

## 禁止

- 不要画成精致写实插画、影楼风、电商详情页风、少女漫画大眼萌。
- 不要给易姐换装、加复杂配饰、加场景纵深。
- 不要让易姐只站在旁边微笑当装饰。
- 不要让易姐抢走结构表达。
- 不要把面部画得太写实细腻（保持极简淡彩）。

## 判断标准

与 小黑 相同：去掉易姐，图的核心隐喻还能完全成立，说明她太装饰了；要重写提示词，让她成为动作主体。
